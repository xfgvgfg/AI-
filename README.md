# AI 辅助投稿分析小工具 - 使用说明

## 这是什么工具？

一个帮助社区志愿者快速处理投稿的 AI 小工具。你只需把投稿内容粘贴进去（或提供文章链接），AI 会自动帮你：

- **分类**：判断属于哪类事件（环境卫生、物业管理、劳动纠纷、教育安全等）
- **五要素摘要**：提取时间地点、涉及主体、舆情动态、矛盾焦点、敏感程度
- **四维评分**：影响范围、传播潜力、紧急程度、处置难度（1-10分）
- **类似事件参考**：联网查找相似案例并给出处理结果和参考链接
- **行动建议**：分阶段给出具体的志愿者行动指引
- **风险预判**：评估风险等级和发展路径

## 快速开始=

### 命令行启动

```bash
pip install -r requirements.txt
python app.py
```

启动后，在浏览器中访问 `http://127.0.0.1:7861` 即可使用。

## 如何使用

### 1. 配置 AI 模型和密钥

页面左侧顶部可配置：

- **选择 AI 模型**：DeepSeek / 通义千问 / 智谱 GLM / Kimi（均支持联网搜索）
- **输入 API 密钥**：粘贴从平台复制的密钥

> 密钥保存在本地 `user_config.json` 文件中，下次打开页面会自动加载，无需重复输入。

### 2. 输入投稿内容

支持两种方式：

**方式一：粘贴文本**

- 直接粘贴事件描述文字

- 支持微信聊天记录、小红书帖子、抖音文案、微博内容等

- 点击"分析文本内容"按钮

<img width="1403" height="732" alt="image" src="https://github.com/user-attachments/assets/f3e9c462-d186-4e8c-8e3f-4eab64567068" />


**方式二：从链接获取**

- 切换到"从链接获取"标签页

- 粘贴文章 URL（支持新闻、公众号文章等公开页面）

- AI 会自行访问该链接进行分析

- 点击"分析链接内容"按钮
<img width="1411" height="747" alt="image" src="https://github.com/user-attachments/assets/ffca27c7-8579-4f85-a23e-18c87ea53458" />

 
### 3. 查看分析报告

右侧显示完整的 Markdown 格式分析报告，包含：

- 事件标题与分类

- 五要素核心摘要

- 四维度细项评分

- 类似事件参考（带查找指引和真实链接）

- 风险预判与升级建议

- 分阶段行动建议

- **导出 TXT**：纯文本格式

- **导出 Word**：带格式的 Word 文档

## 分类说明

工具支持以下主分类：

- **环境卫生**：污染排放、噪音扰民、垃圾处理等
- **物业管理**：业主纠纷、公共设施维护、停车管理等
- **劳动纠纷**：工资待遇、劳务争议、招聘就业等
- **教育安全**：校园管理、教学政策、校园安全等
- **公共设施**：道路桥梁、路灯、供水供电等
- **邻里矛盾**：噪音、装修、邻里关系等
- **经济消费**：物价、消费维权、商业纠纷等
- **文化非遗**：文化活动、非遗保护、传统手工艺等
- **政策咨询**：政务咨询、政策解读、办事指引等
- **其他**：不属于以上类别的投稿

## 技术说明

- **界面框架**：Gradio 6.x
- **AI 模型**：DeepSeek / 通义千问 / 智谱 GLM / Kimi（均通过 OpenAI 兼容 API 调用）
- **联网搜索**：所有提供商均支持联网搜索（通过 API 参数启用）
- **报告导出**：TXT 格式 / Word 格式（python-docx）
- **配置持久化**：`user_config.json` 保存最后使用的提供商和密钥
- **运行环境**：Python 3.8+
